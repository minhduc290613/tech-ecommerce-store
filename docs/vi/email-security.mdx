# Email và bảo mật

Có thể dùng SMTP hoặc Resend API cho email giao dịch và recovery password. Cấu hình sender domain với SPF, DKIM và DMARC; không đưa password vào Admin form hoặc Git.

## Secrets

Secrets như SMTP password, Resend key, PayOS key, service role và JWT secret chỉ ở Render/aaPanel/server environment. Frontend chỉ nhận public Supabase config.

## Recovery

Cấu hình redirect URL local, preview và production trong Supabase Auth. Kiểm thử email reset trên domain HTTPS trước khi công bố.

Xem [SMTP_SETUP_BILINGUAL.md](../SMTP_SETUP_BILINGUAL.md) và [RENDER_ENV_SETUP_BILINGUAL.md](../RENDER_ENV_SETUP_BILINGUAL.md).
