# Brand assets

## Vietnamese

- `nexora-logo.svg`: logo vector dùng cho README, docs site và tài liệu marketing.
- `nexora-project-banner-vi.svg`: banner giới thiệu project tiếng Việt.
- `nexora-project-banner-en.svg`: banner giới thiệu project tiếng Anh.
- `nexora-logo.png`: bản raster tương thích với nơi không hỗ trợ SVG.

## English

- `nexora-logo.svg`: scalable logo for the README, docs site, and project materials.
- `nexora-project-banner-vi.svg`: Vietnamese project introduction banner.
- `nexora-project-banner-en.svg`: English project introduction banner.
- `nexora-logo.png`: raster fallback for environments without SVG support.

Keep source-controlled assets free of customer data, private keys, and production-only URLs.
